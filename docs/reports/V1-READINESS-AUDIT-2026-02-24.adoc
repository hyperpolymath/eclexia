This audit covers repository hygiene, documentation structure, QA/CI
validation, security posture, and release readiness after the current

(`+Mustfile+`, `+Trustfile+`, `+Intentfile+` family).

`+security-policy.yml+`).

** `+ecl_tracker_create_ex+` forward-compatible tracker options

quality workflow.
